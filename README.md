# Roza Eats

A responsive English–Malayalam website for the Roza Eats Kerala meal-service concept, a brand under Caroza Pvt Ltd with menu development by Roza Labs.

**Public website:** https://roza-eats-experience.r0shan911.chatgpt.site

## Features

- Six signature Kerala meals, menu filters, portion guides and meal stories.
- Scroll reveals, parallax, CSS 3D-style food motion and an eight-second motion preview.
- Bilingual English/Malayalam interface and mobile layouts.
- Lunch-routine planner with an exact 24-hour cutoff in India Standard Time.
- Downloadable routine preview, FAQs and accessibility/reduced-motion controls.

## Run locally

This is a buildless static website. Serve this directory with any static web server. For example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser.

## GitHub Pages

Serve the `main` branch from `/ (root)` in Settings → Pages. No build step or packages are required. All local image and video assets are included beside the HTML, CSS and JavaScript.

## Launch status

This is a visual and interaction prototype, not a live ordering or payment system. The planner does not reserve delivery capacity or activate subscriptions. Recipe portions are development proposals. Verified nutrition values, final pricing, service areas and operating terms must be supplied before commerce launches.

The AI-created food and editorial images illustrate the concept; they are not documentary evidence of final products, actual staff or tested outcomes. The video is an animated concept, not filmed kitchen footage. General references are linked on the site and do not imply endorsement.

Language and motion preferences are stored in the visitor’s browser. No marketing analytics are included. Google Fonts supplies Manrope and Noto Sans Malayalam, with system fallbacks.

Brand names and artwork remain with their respective owners; no open-source licence has been granted by this repository.
